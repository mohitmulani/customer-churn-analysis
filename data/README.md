# Dataset setup

**Source:** [Bank Customer Churn Prediction Dataset — Kaggle](https://www.kaggle.com/datasets/saurabhbadole/bank-customer-churn-prediction-dataset) by Saurabh Badole.

Download the source CSV from the Kaggle dataset page and place it at `data/raw/Churn_Modelling.csv` before running the scripts. Follow the dataset page's licence and redistribution terms. The raw and processed CSV files are excluded from Git by default.

Expected processed output: `data/processed/customer_churn_clean.csv`.

Dataset citation: Saurabh Badole, *Bank Customer Churn Prediction Dataset*, Kaggle. https://www.kaggle.com/datasets/saurabhbadole/bank-customer-churn-prediction-dataset
